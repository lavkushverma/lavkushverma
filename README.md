## 👨‍💻 About Me

I'm a Cloud / DevOps Engineer focused on AWS infrastructure, cloud operations, automation, and security. My work spans infrastructure provisioning, networking, monitoring, security controls, troubleshooting, and operational improvement.

- ☁️ **Cloud & governance:** AWS infrastructure, multi-account environments, Organizations, and SCPs
- 🔐 **Security:** IAM, KMS, AWS Security Hub, AWS Config, GuardDuty, and least-privilege access
- 🌐 **Networking:** VPC, load balancers, Route 53, ACM certificates, and AWS WAF
- ⚙️ **Automation:** Terraform, CI/CD workflows, scheduled operations, and infrastructure as code
- 📈 **Monitoring:** CloudWatch, Grafana, Prometheus, and operational observability
- 🧰 **Operations:** Production support, troubleshooting, remediation, and root-cause analysis
